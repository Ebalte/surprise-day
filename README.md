# Сюрприз дня

Игра в Telegram: раз в сутки открываешь шоколадное яйцо и получаешь фигурку. Нужно собрать все 16 фигурок сезона. Игра работает внутри Telegram как Mini App и как обычный сайт в браузере.

**Что внутри**

- **Яйцо дня.** Одно бесплатное в сутки, таймер считает сервер. Гарант: после 10 яиц без новой фигурки следующее даёт новую. Серия 7 дней подряд даёт бонусное яйцо, а заморозка раз в неделю прощает один пропуск.
- **Коллекция.** 16 фигурок в 4 рядах альбома, за каждый собранный ряд положена награда. За наборы дают рамки для аватарки. Есть временные события с особыми фигурками.
- **Повторки.** Каждая превращается в осколки. Недостающую фигурку можно купить за осколки: обычную за 30, редкую за 60, эпическую за 120. Легендарную купить нельзя.
- **Друзья.** Награда за друга приходит, когда он открывает первое яйцо. За 3 друзей дают яйцо с гарантированной редкой фигуркой, за 10 — с гарантированной эпической.
- **Подарки и обмен.** Можно дарить и менять только повторки и только с друзьями. Пока обмен ждёт ответа, фигурка зарезервирована. Сервер сам подсказывает обмены, выгодные обоим.
- **Магазин и задания.** Дополнительные яйца за Telegram Stars (25 → 50 → 100, цена сбрасывается с новым яйцом дня) и за рекламу. Каждую неделю появляются задания.
- **Бейдж и таблица лидеров** — для тех, кто собрал всю коллекцию сезона.
- **Игровой бот** напоминает, что яйцо готово, и сообщает о подарках и обменах.
- **Админ-бот** — отдельный бот для администраторов: реклама, настройки без перезапуска, статистика, игроки, рассылка.

## Как устроено

```
seasons/        конфиги сезонов (JSON): фигурки, шансы, цены, альбом, события
server/         сервер: Fastify + Prisma (PostgreSQL) + grammY (игровой и админ-бот)
web/            фронт: React + Vite, Telegram Mini App и обычный сайт
.github/        сборка сайта на GitHub Pages, тесты, «будильник» для сервера
render.yaml     настройка сервера на Render
```

Где это работает (всё бесплатно):

| Что | Где |
|---|---|
| Сайт игры (фронт) | GitHub Pages, обновляется сам при каждом push |
| Сервер и оба бота | Render, разворачивается из репозитория |
| База данных | Neon (PostgreSQL) |
| Чтобы бесплатный Render не засыпал | GitHub Actions раз в 10 минут обращается к серверу |

**Питомец.** Первая фигурка из яйца становится питомцем, сменить его можно в «Коллекции». Время (голод, грязь, усталость, возраст) идёт только у главного питомца, остальные стоят на паузе. Стадии возраста, еда и цены — в `server/src/game/pets.ts`. Мини-игры «Башня вкусняшек» и «ASMR: пузыри и слайм» (`web/src/pet/games.tsx`) списывают энергию при старте, а сервер при финише ограничивает очки по времени игры и выдаёт монеты. Карточка для сторис рисуется в игре, загружается на сервер (`/api/stories`, хранится 3 дня) и публикуется по ссылке; с Telegram Premium на сторис добавляется кнопка-ссылка на игру, без Premium ссылка идёт в подпись.

**Пати: общий питомец на двоих.** На экране «Питомец» есть вкладки «Мой» и «Общий». Игрок создаёт пати (❤️ пара или 🤝 друзья), выбирает фигурку и зовёт второго ссылкой `?startapp=pair_<код>` или кодом из 6 символов. Новый игрок по такой ссылке засчитывается пригласившему как друг. Общий питомец живёт всегда, заботиться может любой из двоих, журнал показывает, кто что делал. Если оба позаботились в один день, растёт серия заботы: каждые 7 дней подряд дают +100 монет каждому. Мини-игры за общего питомца дают очки командной цели дня (300): если оба сыграли и цель выполнена, каждому +40 монет. Выйти из пати может любой, питомец останется второму. Логика — `server/src/game/pairs.ts`.

**Мини-игры и рейтинг дня.** Пять игр: «Башня вкусняшек», «ASMR», «Ритм-пати», «Сортировка», «Прыг-скок» (`web/src/pet/games.tsx`). После каждой игры показывается рейтинг дня по ней (лучший результат каждого игрока за сутки по Москве, партнёр по пати отмечен 💞).

**Напоминания о питомце.** Раз в 10 минут бот проверяет главного питомца каждого игрока и общих питомцев пати. Если питомец хочет есть, в ванну, скучает, хочет спать или проснулся, бот пишет с кнопкой «К питомцу». Про каждую нужду бот пишет один раз, пока её не закроют. На одного питомца не чаще раза в 3 часа, ночью (23:00–9:00 МСК) бот молчит. Про общего питомца пишет обоим. Выключить можно в профиле: «Напоминания о питомце» (`server/src/bot/pet-reminders.ts`).

**Безопасность.** Внутри Mini App каждый запрос подписан данными запуска Telegram (`initData`), и сервер проверяет эту подпись по HMAC при каждом запросе. На сайте вход идёт через виджет «Войти через Telegram», его подпись тоже проверяется. Один Telegram-аккаунт равен одному игроку. Весь рандом и все награды считаются только на сервере, в транзакциях с блокировкой строки игрока. Поэтому двойным нажатием одно яйцо не откроешь дважды, а осколки не потратишь дважды.

## Запуск в Telegram: шаг за шагом

Всё делается мышкой и занимает около 20 минут. Нужны аккаунты на GitHub, [Render](https://render.com) и [Neon](https://neon.tech). На Render и Neon проще всего войти через GitHub.

### 1. Код на GitHub

1. Создайте репозиторий, например `surprise-day`, и загрузите в него этот проект.
2. **Settings → Pages → Source: GitHub Actions.**

Адрес сайта будет `https://<ваш-логин>.github.io/surprise-day/`. Дальше он называется **адрес сайта**.

### 2. Два бота в @BotFather

Откройте [@BotFather](https://t.me/BotFather).

**Игровой бот:**
1. `/newbot`: задайте имя, например «Сюрприз дня», и username, например `SurpriseDayBot`. Сохраните токен.
2. `/newapp` → выберите этого бота. Укажите название, описание и картинку 640×360. На шаге с URL укажите **адрес сайта**, short name — `egg`. Получится ссылка вида `t.me/SurpriseDayBot/egg`.
3. `/setdomain` → выберите бота и укажите `<ваш-логин>.github.io`. Это нужно для входа через Telegram на сайте в обычном браузере.

Оплата в Telegram Stars дополнительной настройки не требует.

**Админ-бот:** ещё раз `/newbot`, например `SurpriseDayAdminBot`. Сохраните токен.

**Ваш Telegram ID** понадобится для доступа к админ-боту. Его подскажет [@userinfobot](https://t.me/userinfobot). Ещё вариант: запустите всё с любым значением, напишите админ-боту `/start`, и он покажет ваш ID.

> Токены — это пароли от ботов. Не публикуйте их и не коммитьте в репозиторий: они вводятся только в настройках Render.

### 3. База на Neon

1. Neon → **New project**, регион Frankfurt.
2. Скопируйте **Connection string** (`postgresql://...?sslmode=require`).

### 4. Сервер на Render

1. Render → **New → Blueprint** → выберите репозиторий. Render прочитает `render.yaml`.
2. Заполните переменные:

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | строка подключения из Neon |
| `BOT_TOKEN` | токен игрового бота |
| `BOT_USERNAME` | username игрового бота без @ |
| `MINI_APP_SHORT_NAME` | `egg` (short name из `/newapp`) |
| `WEB_APP_URL` | **адрес сайта** |
| `ADMIN_BOT_TOKEN` | токен админ-бота |
| `ADMIN_IDS` | ваш Telegram ID (несколько — через запятую) |

`SESSION_SECRET` и `WEBHOOK_SECRET` Render сгенерирует сам.

3. **Apply.** При сборке сервер сам создаст таблицы в базе и загрузит сезон из `seasons/`. Адрес сервера будет вида `https://surprise-day-api.onrender.com`.

### 5. Связать сайт с сервером

В GitHub: **Settings → Secrets and variables → Actions → Variables → New variable**:

| Переменная | Значение |
|---|---|
| `API_URL` | адрес сервера на Render, например `https://surprise-day-api.onrender.com` |
| `BOT_USERNAME` | username игрового бота без @ |

Затем **Actions → «Сайт на GitHub Pages» → Run workflow**. После этого сайт будет обновляться сам при каждом push. По переменной `API_URL` раз в 10 минут работает и «будильник», чтобы сервер не засыпал.

### 6. Проверить

1. Напишите игровому боту `/start`. Должна прийти кнопка «Открыть игру», а в меню чата появится «Играть».
2. Откройте игру и нажмите на яйцо.
3. Напишите админ-боту `/start` — откроется меню администратора.
4. Реферальная ссылка (экран «Друзья») выглядит так: `https://t.me/<бот>/egg?startapp=ref_<id>`.

## Локальный запуск

Нужны Node.js 20+ и Docker (или свой PostgreSQL).

```bash
cp .env.example .env          # впишите BOT_TOKEN; для входа без Telegram — DEV_LOGIN=true
docker compose up -d          # PostgreSQL на localhost:5432
npm install
npm run db:migrate            # создать таблицы
npm run db:sync-seasons       # загрузить сезоны из seasons/*.json

npm run dev:server            # API на http://localhost:3000 + боты (polling)
# во втором терминале:
echo 'VITE_API_URL=http://localhost:3000
VITE_BOT_USERNAME=SurpriseDayBot
VITE_DEV_LOGIN=true' > web/.env
npm run dev:web               # сайт на http://localhost:5173
```

- **В обычном браузере** при `DEV_LOGIN=true` и `VITE_DEV_LOGIN=true` появится кнопка «Войти как тестовый игрок». Виджет Telegram на localhost не работает.
- **Внутри Telegram** Mini App открывается только по https. Для проверки на телефоне пробросьте фронт через туннель (`npx cloudflared tunnel --url http://localhost:5173`) и укажите этот адрес в `/newapp` → Edit → URL. Тот же адрес добавьте в `CORS_ORIGINS`.

**Тесты** (нужна локальная база; они очищают таблицу настроек, поэтому не запускайте их на проде):

```bash
npm test -w server    # 21 тест: вход, яйца, гарант, серия, рефералы, крафт, подарки, обмен, Stars, админ-бот, реклама
```

## Сезоны: замена фигурок и новые сезоны

Всё, что касается контента и баланса, лежит в `seasons/season1.json`. Код менять не нужно.

**Заменить картинки и названия.** Картинки-заглушки лежат в `web/public/figures/season1/*.svg`. Положите свои файлы (svg, png, webp) с теми же именами или поменяйте пути `image` в JSON. Можно указать полный URL. Названия и описания меняются в том же JSON. Поле `code` у фигурки после запуска не меняйте: по нему хранится прогресс игроков.

**Баланс** задаётся в разделе `rules`:
- шансы выпадения (`weight`) и осколки за повторку (`shards`);
- гарант (`pityThreshold`);
- цены в осколках (`craftCosts`);
- лимиты подарков (`trading`);
- цены в Stars и яйца за рекламу (`shop`);
- задания недели (`quests`).

**Альбом:**
- `album.rows` — ряды и награды за них;
- `album.sets` — наборы, за которые дают рамки.

**Событие** добавляется блоком в `events`: даты, шанс выпадения, 2–3 фигурки и бейдж.

**Новый сезон:**
1. Скопируйте `season1.json` в `season2.json` и поменяйте `slug`, `number`, `title`, фигурки и бейдж.
2. У нового сезона поставьте `"isActive": true`, у старого — `false`.
3. Положите картинки в `web/public/figures/season2/`.
4. Закоммитьте. Render при сборке выполнит `db:sync-seasons` сам. Локально: `npm run db:sync-seasons`.

Ошибки в JSON (повтор кода фигурки, редкость без фигурок, два активных сезона) синк покажет понятным текстом и ничего не сломает.

Осколки у игроков общие для всех сезонов, а коллекция и гарант считаются по каждому сезону отдельно.

## Админ-бот

Отвечает только Telegram ID из `ADMIN_IDS`. Команды: `/menu` и `/cancel`.

- **📢 Реклама.** Пошаговое создание кампании. Сначала выберите, где показывать: «за яйцо» (игрок смотрит N секунд и получает яйцо) или баннер на главном экране. Затем пришлите картинку или видео с подписью, ссылку и текст кнопки, длительность и дату окончания. Перед запуском бот показывает предпросмотр. Для каждой кампании видны показы, досмотры, клики и CTR, её можно поставить на паузу или удалить. Яйцо за рекламу выдаётся только на сервере и только если с начала показа прошло нужное время.
- **⚙️ Настройки** без перезапуска и правки файлов:
  - время между бесплатными яйцами (в часах, по умолчанию 24);
  - цены в Stars и в осколках;
  - лимиты подарков и рекламы;
  - гарант, заморозки, шанс фигурок события;
  - выключатели рекламы и техработ.

  Изменённое значение помечено ✏️, и его можно вернуть к значению из конфига.
- **🌙 События.** Запустить событие сейчас на 1, 3, 7 или 14 дней, продлить, остановить или отменить заранее, вернуть даты из конфига. Пока событие не идёт, игроки его не видят (кроме тех, у кого уже есть его фигурки).
- **💳 Покупки.** Итоги продаж за сегодня, неделю и всё время и список последних оплат. В карточке покупки есть кнопка **«Вернуть звёзды»**: звёзды сразу уходят игроку, а неоткрытое купленное яйцо забирается. Если яйцо уже открыто, бот предупредит, что фигурка останется у игрока. Покупки конкретного игрока открываются из его карточки.
- **Выключатель покупок** в «Настройках»: «Покупки за Stars» → выключены. Кнопка покупки в игре пропадает, и даже уже открытый счёт оплатить не получится.
- **📊 Статистика:** игроки, новые за день, активные, открытые яйца, покупки за Stars, реклама.
- **👤 Игрок:** поиск по ID или @username. Можно выдать яйцо, начислить осколки, забанить.
- **📨 Рассылка** всем, кто разрешил уведомления: текст, фото, видео или GIF с подписью (файл до 20 МБ). Перед отправкой бот показывает предпросмотр и просит подтверждение, после отправки присылает отчёт.
- **🎁 Подарки.** Ссылки-подарки со стилем для питомца. Сейчас это набор «Металлист»: косуха (шипастый ошейник и тёмные очки) и комната-картинка с гитарами, постерами вымышленных групп и прожекторами (`web/src/pet/rooms/metal.webp`). Нажмите «Новая ссылка», выберите набор и пришлите, сколько раз всего можно получить подарок (0 — без ограничения). Бот пришлёт ссылку вида `t.me/<бот>/<игра>?startapp=promo_<код>`. Подарок может получить и новый, и уже играющий игрок, каждый по одному разу. Лимит можно изменить, ссылку можно выключить. Новые наборы добавляются в `server/src/game/cosmetics.ts` (а их вид — в `web/src/pet/art.tsx` и `styles.css`).

Все действия администраторов пишутся в таблицу `admin_log`.

## Ограничения бесплатных тарифов

- **Render free** засыпает без запросов. Будильник из GitHub Actions держит его активным, но GitHub иногда запускает расписание с задержкой. Если сервер всё же уснул, первый запрос просыпается около минуты, а Telegram повторяет вебхуки сам. Чтобы этого не было совсем, нужен платный тариф Render (Starter).
- **GitHub отключает расписание**, если в репозитории 60 дней не было коммитов. Тогда включите workflow «Будильник» вручную.
- **Картинки рекламы** хранятся в Telegram и отдаются через сервер. Лимит Bot API на файл — 20 МБ.
